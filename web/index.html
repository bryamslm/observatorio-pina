      Power BI

      El reporte

      Cinco páginas sobre un modelo estrella de 15 tablas y 38 medidas DAX. Está guardado como código (PBIP), así que cada medida y cada visual se pueden revisar en git. La página de operación usa datos simulados con la estructura de un sistema de gestión agrícola y un ERP.

      Método

      Cómo está hecho

      Cada paso es un script que se puede volver a correr sin duplicar datos. Antes de publicar una cifra, la comparé con la que publica la fuente oficial.

      1. Descarga

        WFS de MOCUPP e IGN, API de Comtrade y archivo masivo de FAOSTAT. descargar.py

      2. Limpieza

        Reproyección a CRTM05, cruce espacial por distrito y normalización. procesar.py

      3. Almacén

        SQL Server 2022: modelo estrella, vistas de KPI y un usuario de solo lectura. cargar.py

      4. Modelo

        Modelo semántico de Power BI con 38 medidas DAX, escrito como código. generar_pbip.py

      5. Publicación

        Reporte de cinco páginas y esta página. exportar_web.py

      Errores que encontré en las fuentes

      1. El servicio de MOCUPP declara coordenadas geográficas, pero vienen en CRTM05. Sin corregirlo, el área daba cero.
      2. La capa de 2016 trae 5.959 ha contra las 68.643 publicadas.
      3. En el campo CÓDIGO del IGN, Chomes y San Juan de Abangares tienen el mismo valor. La llave correcta es el código DTA.
      4. Comtrade reporta para 2024 casi el doble del volumen de 2023 con un valor que solo sube 16 %.
      5. Cada año MOCUPP nombra distinto los cambios de cobertura, y Comtrade arrastra nombres históricos como “India (...1974)”.
